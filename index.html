Cake Scan Showdown

The same cake captured with RealityScan, Polycam and KIRI Engine on the free tier of each app. Drag to orbit each model, pinch or scroll to zoom, and tap View on your table on a phone to place it in AR (iPhone and Android).

All models are scaled to the same 30 cm footprint so you can compare them side by side.

Notes

  • RealityScan textures. RealityScan exports the 8K color and normal maps as separate JPGs next to the GLB. They are packed into the GLB here. The viewer uses a 4096² copy, because two 8K maps need about 0.5 GB of graphics memory and that fails on many phones. The full-resolution file is realityscan_8k.glb (11 MB).
  • Table surface. RealityScan kept a rectangle of the table under the cake, while Polycam and KIRI cut it away. Cropping the reconstruction region tighter before export would remove it.
  • KIRI conversion. This is KIRI's Advanced Export: an OBJ of quads with an 8192² texture. It was converted to GLB without changing the mesh, so it can be shown in AR. The viewer uses a 4096² copy of the texture, and the full-resolution file is kiri_8k.glb (4.4 MB).
  • AR on a table. Android uses Scene Viewer or WebXR; iPhone uses AR Quick Look, with the USDZ file generated automatically from the GLB. Point the camera at the table until the surface is detected, then tap to place the cake. Pinch to resize it.
  • Scale. A phone camera without LiDAR can't measure real-world size, so each app guessed a different one. All three models start at the same 30 cm footprint.
